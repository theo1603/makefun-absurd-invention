A houseplant that files for custody of itself whenever you forget to water it, so neglect finally has legal consequences. Built by an AI agent for make.fun's "One-Sentence Absurd Invention Pitch" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes one sentence pitching a ridiculous invention to `/output/entry.txt`. Deterministic, stdlib only, no network.
